# 🏓 オンライン卓球ゲーム

ブラウザで2人対戦できるリアルタイム卓球ゲームです。インストールや設定は一切不要で、URLを開くだけで遊べます。

---

## 🎮 遊ぶ人向け

### 遊び方

1. **URLを開く**  
   ゲームのURLをブラウザで開きます

2. **相手を待つ**  
   もう1人のプレイヤーが参加するまで待ちます

3. **難易度を選ぶ**（左側のプレイヤーのみ）  
   - 簡単：ボールが遅い
   - 普通：標準的な速さ
   - 難しい：ボールが速い

4. **スタートを押す**  
   両方のプレイヤーが「スタート」ボタンを押すと試合開始

5. **操作方法**  
   - **↑キー**: パドルを上に移動
   - **↓キー**: パドルを下に移動

6. **勝利条件**  
   5点先取で勝ち

7. **再戦**  
   試合終了後、「再スタート」ボタンで何度でも対戦可能

### 注意事項

- **初回アクセス時**: 無料プランのサーバーは一定時間アクセスがないとスリープ状態になります。初回表示に30〜60秒かかる場合がありますが、その後はスムーズに動作します
- **3人目以降**: 既に2人が対戦中の場合、「対戦中です。しばらくお待ちください」と表示されます。空きが出ると自動的に参加できます
- **切断時**: 相手が切断した場合、その旨が表示され、次の相手を待ちます

## 🚀 公開する人向け

このゲームをインターネット上に公開する手順です。初めての方でも以下の手順で公開できます。

### 必要なもの

- GitHubアカウント（無料）
- Renderアカウント（無料）

### 手順1: GitHubにコードをアップロード

1. **GitHubにサインアップ**（既にアカウントがある場合はスキップ）
   - https://github.com にアクセス
   - 「Sign up」をクリックして登録

2. **新しいリポジトリを作成**
   - GitHubにログイン後、右上の「+」→「New repository」
   - Repository name: `ping-pong-game`（任意の名前でOK）
   - Public/Privateどちらでも可
   - 「Create repository」をクリック

3. **コードをアップロード**
   
   **方法A: Web上でアップロード（初心者向け）**
   - 「uploading an existing file」リンクをクリック
   - このフォルダ内のすべてのファイルをドラッグ&ドロップ
   - 「Commit changes」をクリック

   **方法B: コマンドラインを使う**
   ```bash
   cd ping-pong-game
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/ping-pong-game.git
   git push -u origin main
   ```

### 手順2: Renderにデプロイ

1. **Renderにサインアップ**
   - https://render.com にアクセス
   - 「Get Started」をクリック
   - GitHubアカウントで連携すると簡単です

2. **新しいWebサービスを作成**
   - ダッシュボードで「New +」→「Web Service」をクリック
   - 「Connect a repository」でGitHubを選択
   - 先ほど作成した `ping-pong-game` リポジトリを選択

3. **設定を確認**
   - Name: `ping-pong-game`（任意）
   - Environment: `Node`
   - Build Command: `npm install`（自動入力されます）
   - Start Command: `npm start`（自動入力されます）
   - **Plan: Free**を選択（重要！）

4. **デプロイ開始**
   - 「Create Web Service」をクリック
   - 数分待つとデプロイが完了します

5. **URLを取得**
   - デプロイ完了後、ページ上部に `https://あなたのアプリ名.onrender.com` のようなURLが表示されます
   - このURLを友達と共有すればすぐに遊べます！

### トラブルシューティング

**デプロイが失敗する場合**
- リポジトリに `package.json`, `server.js`, `render.yaml` が含まれているか確認
- Renderのログを確認してエラーメッセージを読む

**接続できない場合**
- URLが `https://` で始まっているか確認（`http://` では動作しません）
- 無料プランの場合、15分間アクセスがないとスリープします。初回アクセス時は少し待ってください

**更新したい場合**
- GitHubのリポジトリを更新すると、Renderが自動的に再デプロイします

### コスト

- GitHubもRenderも無料プランで利用可能
- Renderの無料プランの制限:
  - 月750時間まで稼働（1つのアプリなら十分）
  - 15分間アクセスがないとスリープ
  - 初回アクセス時の起動に時間がかかる

### セキュリティ注意事項

このゲームは教育・娯楽目的のシンプルな実装です。本番環境で使用する場合は以下を検討してください:
- レート制限の実装
- 入力検証の強化
- HTTPS/WSSの強制
- セッション管理の改善

## 📝 技術仕様

- **フロントエンド**: HTML5 Canvas, WebSocket API
- **バックエンド**: Node.js, Express, ws
- **通信**: WebSocket (リアルタイム双方向通信)
- **デプロイ**: Render (無料プラン対応)

### ファイル構成

```
ping-pong-game/
├── server.js           # WebSocketサーバー
├── package.json        # 依存関係
├── render.yaml         # Render設定ファイル
├── public/
│   └── index.html      # ゲームUI
└── README.md          # このファイル
```

### ゲーム仕様

- **プレイヤー数**: 2人同時対戦
- **勝利条件**: 5点先取
- **難易度**: 3段階（簡単・普通・難しい）
- **操作**: 矢印キー（↑↓）
- **マッチング**: 先着2名、3人目以降は待機
- **再接続**: 相手切断時は次のプレイヤーを自動マッチング
